# Pull Request Comment Responses

Whenever posting a response to a GitHub pull request comment or review thread, append the following disclosure as the final paragraph:

`comment generated with {model name}`

Replace `{model name}` with the name of the model generating the response. Apply this requirement regardless of whether the response is created through a slash command or another workflow.
